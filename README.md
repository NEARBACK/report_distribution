# Отчёт по раздаче для Excel

Скрипт собирает районные отчёты в один файл Excel `.xlsx`. Каждый день будет на отдельной вкладке, а итоги по блюдам — в строке «ОБЩИЙ».

## Первый запуск на Windows

1. Установите Python 3.10 или новее. Если установщик предлагает **Add Python to PATH**, отметьте этот пункт. [Скачать Python для Windows](https://www.python.org/downloads/windows/)
2. Скачайте проект через **Code → Download ZIP** и распакуйте архив.
3. Откройте распакованную папку, в которой лежит `generate_report.py`. Нажмите на адресную строку Проводника, введите `cmd` и нажмите Enter.
4. В открывшемся окне выполните команду. Это нужно сделать один раз.

   ```bat
   py -m pip install -r requirements.txt
   ```

Если Windows пишет, что команда `py` не найдена, попробуйте `python` вместо `py` в командах ниже и выше.

## Как собрать отчёт

1. Создайте папку `report_data` рядом с `generate_report.py`.
2. Скопируйте в неё районные файлы `.xlsx` за один месяц. Имя каждого файла должно начинаться с номера зоны и дефиса, например `25-район ноябрь 2026.xlsx`.
3. В том же окне выполните:

   ```bat
   py generate_report.py report_data
   ```

4. Откройте готовый файл в Excel. Он появится рядом со скриптом, например `Раздача 2026-11.xlsx`.

Если отчёт с таким именем уже есть, задайте новое имя:

```bat
py generate_report.py report_data -o "Раздача 2026-11 обновлённая.xlsx"
```

Для следующего месяца замените файлы в `report_data` и повторите запуск. Скрипт берёт количества из строки 3 «Принял». Если за день по зоне нет отчёта, её строка остаётся пустой.
